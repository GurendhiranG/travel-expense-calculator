# Travel Expense & Distance Calculator

A responsive React/Vite calculator for comparing Indian travel costs across car, bus, train, flight, taxi, and bike options. It supports OpenStreetMap geocoding, OSRM routing with fallback estimates, fuel calculations, passenger splitting, professional expense categories, Indian Rupee formatting, and route visualization.

Projects:
- Calculator: artifacts/travel-expense-calculator
- Animated overview: artifacts/travel-expense-calculator-video

Development:
Install dependencies with pnpm, then run the artifact workspace you want.
